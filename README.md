## StudyFlow – Student Dashboard and Study Planner

StudyFlow is a MERN stack web application designed to help students organize their academic activities through a centralized dashboard.

### Features
- Task and event management (CRUD operations)
- Urgent and upcoming task overview
- Daily schedule and calendar
- Grade and assessment tracker
- Study resource library
- User authentication and account settings

### Technology Stack
- **Frontend:** React, CSS, Axios, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
